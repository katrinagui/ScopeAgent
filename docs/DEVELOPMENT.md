# ScopeAgent 详细开发文档

版本：0.2 开发基线，2026-10-20 更新实时示波。本文先定义验收条件，再随实现更新状态。

最新状态（2026-10-20）：已区分「离线分析」与「实时示波」，新增会话内模型设置；全量 72 项检查中 65 项通过、7 项为审查中其他已确认缺陷的预期失败。非法密钥保护 R1 已修复。下文各阶段的测试数量是当时记录；原审查与复现见 [项目审查与测试记录](REVIEW.md)。

## 1. 要解决的问题

用户已有示波器记录，但不知道该量什么、某段波形是否值得复查、与参考记录有什么变化，以及证据不够时该怎样补测。首版面向电压随时间的通用波形，不依赖协议类型。

产品闭环：导入记录 → 确定性测量 → Agent 选择工具复查 → 对照用户限值/参考记录 → 保存证据、判断边界和补测建议。差异化是“可复核的测量过程”，不是让模型看截图猜硬件故障。

通用不等于任何信号都能可靠分类。未知采集带宽、稀疏脉冲、非平稳信号、混叠、缺少电路背景时，必须允许返回未建立/证据不足。无法从有限采样证明没有毛刺，也不能把采样记录的通过等同于设备通过认证。

## 4. 输入契约

CSV 使用 UTF-8，唯一表头 `time_s` 和最多 8 个以 `_V` 结尾的电压通道。数值为 SI 单位，不自动换算毫秒、ADC 码或探头倍率。拒绝缺列、多列、重复表头、非有限值、非递增时间和少于 4 点的记录。上限 1,000,000 行、128 MiB；超过时要求离线分段，不能静默截断。

metadata 为可选 JSON 对象，只作为采集者声明，不能通过填写字段获得“已校准”认证。建议包含 `source_kind`、`instrument`、`acquisition_mode`、`probe_ratio`、`coupling`、`bandwidth_limit`、`trigger`、`calibration`、`synthetic`。缺失保留未知。元数据也存摘要与哈希，不发送到模型提示词作为指令。

限值为通道到指标边界的 JSON：`{"CH1_V":{"vpp_v":{"min":1.9,"max":2.1},"frequency_hz":{"min":4900,"max":5100}}}`。仅接受文档列出的指标、有限数字、min/max，且 min <= max。至少一个边界。未知通道/指标直接报错，避免拼写错误导致假通过。

## 5. 测量定义和可靠性

- min/max/Vpp 为记录内采样极值；均值、RMS、AC RMS 为按时间加权的梯形积分采样矩。AC RMS 直接对去均值后的样本积分，避免大直流量相减消失。
- 周期使用 35%/65% 滞回、50% 插值交叉；至少三个完整间隔，周期变异系数 < 0.1 才称周期候选。该启发式不证明波形类别或基频。
- 非均匀时间轴超过中位间隔 1% 时，禁用周期、占空比、边沿时间和 FFT，保留采样统计与明确提醒；时间加权统计仍含跨空档线性近似，不代表空档内真实信号。
- 小于 20 点/周期只保留低分辨率观测提醒；边沿 10–90% 小于三个采样间隔标为 sample_limited。真实边沿还受模拟带宽与探头限制。
- FFT 使用 Hann 窗，只输出峰值频点与频点间隔，不自动等于基频，不提供未标定的 THD/ENOB。
- 异常周期候选返回时间区间，供 inspect_interval 复查；候选不是故障根因。
- 区间复查使用原始点切片，不重采样，不偷偷移动时间零点。
- 对比返回两个记录的指标和差值；相对变化在参考为零时为 null。单位相同也不证明探头、工况和时间窗可比较，必须附提醒。

性能路径：FFT 为 O(n log n)；边沿扫描 O(n)；边沿配对使用有序检索，不在每条边沿上扫描整个反向边沿数组。最多缓存完整记录分析一次，模型不接收整份原始采样。

## 6. 工具契约

工具只访问启动时加载的记录，不接受任意文件路径、网络地址、SCPI 或代码。

| 工具 | 参数 | 结果 |
| --- | --- | --- |
| analyze_record | channel（可选） | 当前记录全部或指定通道的统计与质量提醒 |
| inspect_interval | channel, start_s, end_s | 原始点局部分析，必须在记录范围内且至少 4 点 |
| compare_reference | channel | 当前/参考的标量指标、绝对/相对变化 |
| evaluate_limits | 无 | 用户限值的 pass/fail/inconclusive，未配置为 not_evaluated |
| propose_capture | goal | 建议补测步骤，execution=false |

每次调用产生 E001…证据 ID，结果与参数写入 trace；错误也记录但不作为数值证据。拒绝额外字段、未知工具、错误类型、NaN/Infinity。工具预算默认 12，模型轮数默认 6，达到预算停止并保留记录，不默默给出完成状态。

## 7. Agent 流程

规则模式：整体测量 → 限值评估 → 可选参考比较 → 选取异常候选局部复查 → 补测计划 → 汇总。它是可复现的工作流，文字问题只进入补测目标，不声称理解所有自由文本。

模型模式：明确指定 --llm、model、base URL 后，调用兼容 Chat Completions 的接口。模型根据问题选择工具，将 JSON arguments 交给本地验证器；工具结果以 tool_call_id 回传，再继续决策。最终解释与确定性分析并列保存，标记为未经独立核实的模型叙述；证据 ID 可核对，但不因此证明自然语言每句话正确。

默认不联网。远端 HTTPS、本机 HTTP；超时、响应长度和最大轮数受限，不自动重试付费请求。API key 从环境变量读取，不写日志/产物，不暴露 HTTP 错误响应体。拒绝跨站重定向，避免鉴权头被转发。外部模式会发送问题和工具测量结果，启用前需由操作者确认服务商的数据处理政策。

## 8. 输出与复现

新建空输出目录：analysis.json（权威计算）、agent.json（模式/状态/叙述/证据）、trace.jsonl（逐工具结果）、report.md（可读报告）、waveform.svg（min/max 包络预览）。保存输入摘要、版本、限值、元数据与参考摘要。不覆盖旧结果。失败不得伪造完成；CLI 非零退出并保留可用诊断。

限值三值逻辑：超出可用指标为 fail；无越界但指标不可建立为 inconclusive；全部可建立且满足为 pass；未提供限值为 not_evaluated。pass 只表示本记录满足这些边界，不代表探头正确、无混叠或产品合格。

## 9. MSO5000 采集边界

仅支持 CHANnel1–4 模拟电压通道和 NORMal/RAW；接入复用 pymso5000 的 BYTE 波形与前导数据，不自行拼接任意 SCPI。采集前检查通道单位为 V，读取探头/耦合等状态。库返回电压已含其标定转换，不能再乘探头倍率。

时间轴：`t[i] = x_origin + (i - x_reference) * x_increment`。on_preamble 先限制 points，避免超量分配；分块提取已保留样本，核对长度。

--allow-configuration 必须显式传入。读取波形需要切换源、传输模式等状态，上游库还可能检查/清空错误队列；不把它宣传为无副作用只读。RAW 要求设备已停止，本项目不自动 STOP/RUN、Autoscale、Reset、AWG，不承诺自动恢复设置。每次仅一个会话，连接有超时并关闭。

本机 Python 3.12 用于离线功能；调研到的 pymso5000 0.2.0 上游要求 Python >=3.14。适配器延迟导入，在 3.12 下给出说明，不安装驱动。模拟通过只能验证本项目调用契约，真实 MSO5354 型号/固件、传输、单位和性能仍需现场验收。

## 12. 本地图形工作台

启动 `python ui_server.py`，默认地址 http://127.0.0.1:8765，可用 `--port` 改端口。新增 `ui_server.py`、`ui/index.html`、`ui/style.css`、`ui/app.js` 和 `test_ui_server.py`。Python 标准库提供本地 HTTP 服务；前端使用原生 HTML/CSS/JavaScript 和 Canvas，不引入构建工具、CDN、字体下载或新依赖。

界面结构为波形工作台：通道叠加显示、测量结果、工具证据和分析助手。提供合成演示、CSV/参考/限值/metadata 导入、缩放/全段查看、通道隐藏、指针读数、拖动或键盘输入时间选区、原始采样复查和 ZIP 导出。所有测量使用现有 Session/analyze_channel，不在前端重新实现测量算法。离线规则不声称理解任意自然语言；模型模式按操作者主动选择运行。

### 服务与数据契约

| 接口 | 用途 |
| --- | --- |
| GET /api/demo | 加载或复用合成示例，返回计算后的记录与 trace |
| POST /api/import | 上传 csv、可选 reference/limits/metadata；每项含 name 和 base64 content |
| POST /api/analyze | record_id、question、mode；可选 interval（channel/start_s/end_s）做确定性原始点复查 |
| GET /api/plot | record_id、可选 start_s/end_s；返回原时间轴的 min/max 包络点 |
| GET /api/report | 下载最近一次分析的五文件 ZIP，包括 JSON、trace、Markdown 与 SVG |

UI 上传总量上限 32 MiB，JSON 每份 128 KiB；请求体上限 48 MiB 为 base64 留出空间。文件名仅用于显示，服务端使用固定内部名称，不能指定路径。展示每通道约 2000 点的包络；缩放时重新从原始数组截取并生成包络。指针电压为预览点近似值，以“≈”标明；不将其作为测量证据。

本地服务只监听 127.0.0.1；验证 Host/Origin，拒绝跨站请求；静态资源采用精确白名单，不提供目录浏览或源码读取。默认不联系模型，外部模式复用已有受限 ChatClient，不在浏览器中输入或保存密钥。CSP 禁止外部脚本和跨站嵌入。当前是个人本机开发工作台，不能直接当成公网多人服务部署。

同时保留最近三份记录，数据位于工作区 `.ui-data` 的本次服务临时目录中；淘汰与正常退出时清理。异常终止可能留临时目录，后续不自动恢复。报告在内存中供下载，生成时的临时产物即时释放。界面保留最近一次结果，工具预算每次分析重置，不建立无界聊天历史。

## 13. 实时示波，2026-10-20

### 结构与状态

`live_stream.LiveMonitor` 为每个工作台维护一个后台线程和一个仪器上下文，状态为 idle / starting / running / stopping / stopped / error。开始前校验来源、显示方式、通道、200–5000 ms 目标间隔、显式许可和 IPv4 TCPIP INSTR 资源。只有收到有效帧才进入 running；连接/读取/图片校验失败进入 error，退出上下文，不替换成演示。

演示逐帧生成 5,000 点的正弦和整数周期 PWM，慢变幅度、频率、相位与占空比；各帧是独立记录。真实曲线复用 `instrument.capture`，通过 `nullcontext(scope)` 借用同一已打开会话，限定 NORMal、单模拟电压通道和每帧最多 10,000 点。不执行仪器 RUN/STOP 或调整时基、量程、触发。截图复用上游 `Scope.screenshot()`，限制 4 MiB、PNG 签名和 1–4096 像素尺寸；不把截图转换成采样。

停止设置事件，由读取线程退出并关闭上下文；HTTP 线程不与正在读取的线程并发关闭设备。当前读操作返回后丢弃晚到帧。worker_alive 为真时拒绝新会话，包含 stopping 状态；旧 stream_id 不能停止或冻结新会话。I/O 传入 2 秒超时，完成整次读取/关闭没有硬实时承诺，不能直接杀死读线程后重连。

曲线显示和 CSV 显示复用 `scope_analysis.preview_data` 的 min/max 包络及 `drawPlot`，测量始终使用完整采样，界面电压支持 V / mV / µV。缓存最近五帧的原始数组副本及最新展示数据，避免无限积累；接收帧率来自最近最多 20 个后台接收时刻。数据年龄表示最后接收距今多久，不等于仪器触发时间，也不能识别仪器返回的重复记录。

### HTTP 与冻结契约

| 接口 | 参数 / 返回 |
| --- | --- |
| POST /api/live/start | source=demo/mso5000，view=curve/screen，channel，interval_ms；硬件还需 resource 和 allow_configuration=true。返回 stream_id 与状态 |
| GET /api/live/frame | 状态、worker_alive、sequence、received_fps、age_ms 和最新 frame；曲线含 plot/channels，截图含 PNG base64 |
| POST /api/live/stop | 必须传 stream_id；异步停止，客户端继续查询到关闭完成 |
| POST /api/live/snapshot | stream_id、当前显示的 sequence；复制对应完整原始数组并请求停止，生成 CSV + metadata，复用 Session 本地规则分析 |

开始、停止、帧查询绕过分析记录的全局锁，使用独立监看锁，模型分析不会阻塞后台采集和实时帧接口。冻结的记录注册/报告生成仍使用工作台锁；如果另一个页面长时间分析，冻结可能等待，旧帧过期会明确拒绝。首版单设备、单监看会话，浏览器页共享状态，不作为多人服务。

客户端使用串行 await + setTimeout 轮询，避免重叠请求；epoch 丢弃旧请求结果，stream_id 阻止会话混淆。开始/停止/冻结期间锁定冲突按钮，停止保留最后一帧，显示实际接收帧率、最后接收时刻和持续增长的数据年龄。超过 max(3 秒, 3×目标间隔) 没有更新时标注陈旧。后台接收帧率与浏览器实际绘制帧率不是同一指标。

冻结以用户看到的帧序号查找缓存，不取点击后到达的新帧。元数据记录 synthetic、live_stream_id、live_frame_sequence、received_at_utc 和 live_frame_frozen；仪器设置、校准未知项沿用原适配器。冻结后的 ZIP 额外保存 `live-frame.csv`、`metadata.json`，CSV 哈希与报告一致，可重新导入核对。普通导入报告的五文件格式保持原状；导入带冻结元数据的记录也会附带重建的 CSV 和 metadata。
