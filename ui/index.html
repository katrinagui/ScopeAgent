使用说明

展开下方章节，查看连接步骤与实用操作。

先确认使用条件

没有设备：Python 3.12+ 与 NumPy 即可体验动态演示。有设备：选择「实际示波器」，扫描或填地址后识别实际厂商、型号和序列号，再匹配功能。扫描需要 VISA 后端；当前波形 / 截图适配器仍为 MSO5000，需 Python 3.14+ 与 pymso5000 0.2.0。其他型号可显示身份，但未适配时不能监看。LAN、USB 和真实设备兼容性均待现场验收。

文件夹内可双击「打开网页工作台.cmd」启动并打开浏览器；已有服务时可直接双击「网页入口.url」。两者默认使用 8765 端口。

01没有设备：先体验动态演示
  1. 打开实时入口

    关闭本说明，在左侧导航点击「实时示波」；窄屏中对应波形图标。数据来源保留「合成演示」，查看方式为「波形曲线」。

  2. 开始观察

    选择 500 ms 目标刷新间隔，点击「开始监看」。黄色为正弦、青色为 PWM；软件每帧重新生成 5,000 点 / 通道，幅度、频率和占空比会缓慢变化。点击通道标签可隐藏 / 显示曲线。

  3. 把观察交给 Agent

    留意下方的峰峰值、RMS 和阈值占空比；点击「冻结此帧并分析」，进入该帧的完整采样分析。也可先「停止监看」，保留最后一帧再冻结。

演示是动态合成信号，不是示波器采样，也不是旧 CSV 循环播放。无需 API Key、硬件依赖或连接许可；演示模式没有仪器原屏截图。

02连接示波器：接线、IP 和运行环境

1. 接好网络与待测信号

将示波器后面板的 LAN 网口接到路由器 / 交换机；电脑接入同一可互通的局域网。电脑可以有线或无线接入，但访客 Wi-Fi、客户端隔离、不同 VLAN 等设置可能阻断通信。

把探头接到待测通道，在示波器面板上先确认能看到信号，核对输入限值、接地方式、探头倍率、电压单位 V、量程、耦合与触发。本项目不会自动打开通道或替你调整时基、量程、触发。

2. 在示波器上查 IP（以 MSO5000 为例）

MSO5000 官方手册的路径为 Utility → IO → LAN。有路由器分配地址时，可使用 DHCP，等待网络配置成功，记下 LAN 页面显示的 IPv4 和 VISA 地址；不同固件的文字可能略有不同。

例如，设备实际显示 192.168.1.100 时，可输入该 IP，或 TCPIP::192.168.1.100::INSTR。也接受带主机名的 TCPIP INSTR、完整 USB INSTR 资源；USB 地址应从 VISA 后端或厂商工具获取，不能只填「USB」。不接受 http://、网页路径或 SOCKET 资源。扫描可能发现不完整，此时手动填实际地址再识别。

两个地址不要混淆：http://127.0.0.1:8765/ 是电脑上的工作台；设备 IP 填在「IP / VISA 地址」输入框中。打开工作台并不表示已经连接示波器。

没有路由器，电脑与示波器网线直连怎么办？

可使用同一网段的静态 IPv4。仅作示例：专用有线网卡设为 192.168.50.10，示波器设为 192.168.50.20，双方子网掩码均为 255.255.255.0。两个地址必须不同，且该网段不能与现有网络冲突。

在示波器 LAN 页面使用 Static IP 时，按手册关闭 DHCP 和 Auto IP，再填写静态参数。电脑则修改连接示波器的那块有线网卡的 IPv4 设置。同网段直连通常不需要网关 / DNS。修改前记下原设置，结束后恢复；不要直接覆盖电脑正在使用的联网网卡设置。

3. 准备硬件环境并启动工作台

下面是在项目目录执行的 Windows PowerShell 命令。先准备已安装的 Python 3.14+；没有 py 启动器时，使用该 Python 的完整路径。仅体验演示不需要执行这些命令。

# 在项目根目录执行（ui_server.py 所在目录）
py -3.14 --version
py -3.14 -m venv .venv-hardware
.\.venv-hardware\Scripts\python.exe -m pip install -r requirements-hardware.txt
.\.venv-hardware\Scripts\python.exe -c "import sys, importlib.metadata as m; print(sys.version); print(m.version('pymso5000'))"
.\.venv-hardware\Scripts\python.exe ui_server.py

检查结果应为 Python 3.14+、pymso5000 0.2.0；依赖文件会带入 PyVISA / PyVISA-py 等库。依赖安装成功不等于设备已连通，VISA 后端和网络仍需验证。

如果旧工作台已占用 8765 端口，先导出要保留的报告，在原服务终端按 Ctrl+C 结束，再用硬件环境启动。只在另一个终端安装依赖不会升级旧服务进程。浏览器继续访问启动时打印的本机地址。

4. 在界面建立会话

  1. 识别实际设备

    实时示波 → 数据来源选「实际示波器」→「扫描已连接设备」，再从下拉框选择实际返回的设备。也可填 IP / 完整 VISA 地址，点击「识别这台设备」。扫描与识别仅发送 *IDN?，不会调整波形配置；最多检查 8 个资源，不扫描整段网段。

  2. 核对身份与支持状态

    检查厂商、型号、序列号、固件和地址是否符合实际。没有适配器或身份读取失败时，不能开始监看；可由仪器导出 CSV 后离线分析。通道列表按匹配型号的基础配置生成，已授权升级的额外通道暂不自动探测。

  3. 选查看方式

    有匹配适配器后，要测量与冻结分析，选「波形曲线」，再选择列表中已在仪器面板启用的电压通道。要看仪器屏幕上的菜单、各通道与读数，选「示波器原屏截图」。功能是否可用取决于适配器，而不只是能否识别型号。

  4. 开始并确认数据

    初次建议 1 秒或 500 ms 目标刷新间隔。确认允许建立连接与读取后，点击「开始监看」。首次收到有效帧后才显示「正在监看」；核对来源标记、帧号、接收时刻与仪器面板是否相符。

波形读取可能改变传输源 / 模式并消耗错误队列，不承诺恢复原配置。项目不会发送仪器 RUN/STOP、Autoscale、Reset 或启用输出。首版仅完成源码核对和假设备测试，尚未实机验收。

依据：RIGOL MSO5000 官方用户手册，第 20 章；pymso5000 v0.2.0 依赖声明。

刷新间隔怎么选？

可选 200 ms 至 5 秒。先用 500 ms 或 1 秒；如果传输慢或截图更新不及时，停止后改为 2 秒或 5 秒。设置的是目标间隔，设备与网络不一定能达到；200 ms 不保证每秒五帧。

下面几个状态怎么看？

  • 帧号：本次会话收到的帧序号，重新开始会重置。帧号增长不证明设备产生了新的采集记录。
  • 接收帧率：后台实际收到完整帧的速率，不是示波器 ADC 采样率，也不一定等于浏览器绘制帧率。
  • 接收时刻 / 数据年龄：最后收到一帧的时间和距今多久；不是硬件触发时间。运行中超过 3 秒或目标间隔三倍（取较大者）没有新帧，会标记数据陈旧。
  • 停止与重连：点击「停止监看」结束电脑读取并关闭会话，保留最后一帧；不会停止示波器本身的采集。等「正在断开」结束后，再改来源、通道、视图或刷新间隔，然后重新开始。

这是周期监看，不能连续无遗漏录波。示波器本身已停止采集时，可能重复返回同一记录。罕见毛刺应在仪器上配置硬件触发；未观察到不能证明不存在。

04实用操作：冻结、选区复查与前后对比

用法 A：调试 PWM 频率与占空比

  1. 先在仪器上看清几个周期

    在面板选择合适的时基、量程与触发，再在本项目选择该通道的「波形曲线」。手动改变被测板的工作状态，观察周期候选、峰峰值和阈值占空比是否随之变化。

  2. 保留值得检查的那一帧

    点击「冻结此帧并分析」。工作台会锁定点击时显示帧的完整采样，停止监看并执行本地规则分析；不会自动调用付费模型。

  3. 复查局部证据

    拖动选择时间段，或在下方输入开始 / 结束时间（单位 ms），选择通道并点「复查选区」。选区至少包含四个原始点；周期判断通常还需要更多完整周期。到「证据」展开工具结果，再核对仪器条件。

  4. 保存结果

    点击「导出报告」。冻结帧 ZIP 额外包含 live-frame.csv 与 metadata.json，连同测量、工具证据和预览一起保存。仅有截图时不能执行这套数值分析。

用法 B：比较两种工作状态

先在正常状态冻结并导出一帧，再回到实时示波，复现另一工作状态，冻结并导出第二帧。解压两份 ZIP，通过「导入波形」将第二帧的 live-frame.csv 作为当前波形、第一帧作为参考波形，并附上第二帧的 metadata.json。保持通道名称、探头倍率、耦合、时基与工况说明可比，再查看标量差值；差值本身不等于故障。

可以继续在「分析助手」输入问题。本地规则执行固定测量与补测流程，不能理解所有自由提问；配置模型服务后才能主动选择模型分析。没有测试限值时只给观测，不默认判合格；需要限值判断时，在导入窗口附上限值 JSON。

已有 CSV，也可以直接开始

使用 UTF-8 CSV：时间列为 time_s（秒），电压通道以 _V 结尾（伏特），时间严格递增且至少四点。可选参考 CSV、限值 JSON 和采集说明 JSON；全部上传合计不超过 32 MiB，每份 JSON 不超过 128 KiB。指针读数是预览近似值，正式测量使用原始采样。

最近仅缓存五帧供冻结，画面滞后可能提示帧已过期；先停止并等最后一帧显示，再重试冻结。关闭或刷新页面前先导出重要结果。边沿受采样分辨率限制、FFT 峰不等于基频，不能仅凭一段波形确定电路根因。

05连接不上、画面不动或无法冻结怎么办？
  1. 先检查实际运行的 Python

    提示版本或模块错误时，确认是用 .venv-hardware 的 Python 3.14+ 启动服务，且同一环境安装了固定版本依赖。离线 Python 3.12 可以演示，但不能运行这个硬件适配器。

  2. 再检查物理连接与 IP

    查看网线、示波器 LAN 状态、当前 IP 和子网，排除访客网络隔离、重复 IP 或 DHCP 地址变化。电脑可运行 ipconfig 查看网卡地址，运行 ping 后接实际设备 IP 辅助排查；ping 成功不等于 VISA 可用，失败也可能是 ICMP 被拦截。

  3. 检查资源类型和会话占用

    填写设备 IPv4、TCPIP INSTR 或完整 USB INSTR 资源，不填工作台的 127.0.0.1、网页 URL 或 SOCKET 资源。扫描为空不证明没有设备，可手动输入地址识别；USB 还依赖后端与系统驱动。暂时退出其他占用仪器的控制程序，再检查链路；不要通过关闭整个防火墙来排障。

  4. 画面不变，先看设备是否还在采集

    确认仪器面板的 RUN/STOP 状态、触发条件、已启用通道和输入信号。也可能只是稳定信号重复显示；如果数据年龄持续增长或提示错误，停止监看并核对链路。项目不会自动替你发送 RUN。

  5. 有图但不能冻结

    原屏截图没有数值采样，需停止后切换到波形曲线。曲线尚未收到完整帧、帧已过期或正在断开时也不能冻结。若提示点数超限，核对 NORMal 返回点数；当前实时曲线上限为 10,000 点，不用它代替 RAW 深存储采集。

  6. 等断开完成再重连

    本地服务同时只运行一个监看会话，多个页面共享它；旧会话关闭中会拒绝新连接。读取出错不会替换为演示数据。关闭标签页只会尽力请求停止；浏览器异常退出后，可重新打开工作台停止监看，或正常结束服务。

06本机保存、模型使用与隐私

界面仅监听本机，默认离线。导入记录和冻结帧暂存在工作区 .ui-data，同时保留最近三份；淘汰或正常结束服务时清理，不提供历史恢复。报告需主动导出，普通导入报告不附原始 CSV，请保管自己的输入文件。

模型分析可点击分析助手中的「模型设置」，填写服务地址、模型名称和 API Key；也可在启动前配置 SCOPE_BASE_URL、SCOPE_MODEL 和 SCOPE_API_KEY。页面配置仅对本次服务生效，不落盘，重启后需重新配置；每次保存留空密钥会清除旧值。保存后会自动选中「模型分析」，点击「开始分析」才发送请求。问题、源文件名 / 摘要与工具测量结果会发给配置的服务，不默认发送整份原始采样；模型叙述仍需核对证据。示波器连接许可不等于允许模型自动控制仪器。

连接步骤依据手册与当前实现整理；真实设备仍待现场验收。
