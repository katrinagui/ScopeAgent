# ScopeAgent

用于示波器波形分析的本地工作台：查看采样、复查选区、对比参考记录、评估测试限值，并保留分析证据。可选模型服务，用于选择分析工具和整理解释。

**当前版本：0.2.0 开发版。** 离线流程和动态演示已验证；示波器适配器通过假设备测试，真实设备与外部模型服务尚未验收。已知问题和复现见 [审查记录](docs/REVIEW.md)。

![ScopeAgent 离线分析界面](docs/ui-refined-preview.png)

## 能做什么

| 入口 | 用途 |
| --- | --- |
| 离线分析 | 导入电压 CSV，查看波形，计算幅度、RMS、周期候选与阈值占空比；支持选区、参考记录和用户限值 |
| 实时示波 | 无设备时运行动态合成演示；有设备时识别实际型号，匹配适配器后读取曲线或原屏截图 |
| 测量与证据 | 跳到离线分析下方，查看测量结果和工具执行记录；此入口本身不启动分析 |
| 分析助手 | 使用本地规则流程，或由配置的模型调用受限工具、生成解释和补测建议 |

“离线分析”指分析导入或冻结的记录；选择“模型分析”时仍会访问配置的模型服务。实时曲线可以冻结一帧后分析，截图仅供查看。

## 使用条件

| 使用方式 | 必要条件 |
| --- | --- |
| 离线分析、合成演示、网页界面 | Python 3.12+、NumPy、支持 Canvas 的现代浏览器 |
| 模型分析 | 额外准备支持 Chat Completions 工具调用的服务、模型名称及所需 API Key |
| 真实示波器曲线或截图 | 独立 Python 3.14+ 环境、`pymso5000==0.2.0`、可用 VISA 后端及受支持设备 |

界面无需 Node.js 或前端构建。示波器、API Key 和硬件依赖均不是体验演示的前提。当前主要在 Windows 和 Python 3.12 上验证；其他系统未专项验收。

## 快速开始

以下命令面向原生 Windows Python，在 PowerShell 中执行。仓库当前为私有时，需要先取得访问权限。

```powershell
git clone https://github.com/katrinagui/ScopeAgent.git
cd ScopeAgent
python -m venv .venv-offline
.\.venv-offline\Scripts\python.exe -m pip install -r requirements-offline.txt
.\.venv-offline\Scripts\python.exe ui_server.py --open-browser
```

也可下载仓库后，在项目根目录（`ui_server.py` 所在目录）执行后三条命令。已有满足条件的环境时，直接运行：

```powershell
python ui_server.py --open-browser
```

工作台默认位于 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。首次打开会载入合成记录并执行本地分析。终端需要保持运行，按 `Ctrl+C` 结束服务。

文件夹内还提供两个入口：

- [打开网页工作台.cmd](打开网页工作台.cmd)：启动服务并打开浏览器；优先使用 `.venv-hardware`，其次 `.venv-offline`，最后使用 PATH 中的 `python`。
- [网页入口.url](网页入口.url)：只打开默认网页地址，适合服务已经运行时使用。

服务默认仅监听本机。端口被占用时，可直接使用已运行的工作台，或用 `python ui_server.py --port 8766` 选择其他端口。项目不会自动读取 `.env` 文件。

## 离线分析怎么用

1. 点击 **导入波形**，选择符合下方格式的 CSV。需要前后对比或测试判定时，可展开“参考记录与测试条件”，附上参考 CSV、限值 JSON 和采集说明。
2. 核对文件名、采样点数、通道数和数据来源。
3. 点击通道标签切换显示，用缩放按钮查看波形。指针读数是预览近似值。
4. 拖选时间段，或输入开始和结束时间，选择通道后点击 **复查选区**。界面输入单位为毫秒，计算使用原始采样点。
5. 在 **测量 / 证据** 页签查看结果与调用记录；分析助手中的“信号详情”“补测建议”可展开。
6. 点击 **导出报告** 保存 ZIP。关闭服务前导出重要结果。

测量包括最小值、最大值、峰峰值、均值、RMS、去直流 RMS、周期候选、阈值占空比，以及带采样限制标记的边沿估计。没有测试限值时不会判断合格。

**两种分析方式：** 本地规则执行固定的测量、限值、可用参考对比和补测流程；输入文字主要用于记录目标，不能理解任意自由提问。模型分析可根据问题选择工具，但解释仍需要核对证据。

### CSV 与限值格式

UTF-8、逗号分隔，时间列必须为 `time_s`（秒），电压列必须以 `_V`（伏特）结尾：

```csv
time_s,CH1_V,CH2_V
0.000000,0.10,0.0
0.000001,0.12,3.3
0.000002,0.15,3.3
0.000003,0.18,0.0
```

这四点只用于展示格式，不足以验证周期测量。每份记录支持 1–8 个通道、4–1,000,000 点；时间严格递增，数值有限，不接受多余列、重复表头或缺失值。程序不会自动猜单位、排序、补点或重采样。

网页上传合计上限 **32 MiB**，每份 JSON 上限 **128 KiB**；命令行单份 CSV 上限 **128 MiB**，仍受点数和实际内存限制。

限值文件使用完整通道名，`min` / `max` 可选其一或同时提供，边界包含等号：

```json
{
  "CH1_V": {
    "vpp_v": {"min": 1.9, "max": 2.1},
    "frequency_hz": {"min": 4900, "max": 5100}
  }
}
```

“通过”只表示当前记录满足给定限值；指标无法建立时为“证据不足”。示例 CSV 与限值仅展示格式，并不保证匹配。体验内置演示请使用配套的 [示例限值](examples/limits.json)。全部字段见 [输入格式说明](docs/USAGE.md#4-输入文件的格式)。

## 添加模型

1. 在 **离线分析** 的分析助手下方点击 **模型设置**。
2. 填写服务商的 **Base URL、模型名称、API Key**。Base URL 填 API 根地址，不含 `/chat/completions`；远端必须使用 HTTPS，本机服务可用 HTTP。
3. 点击 **保存设置**，模型分析会自动选中。输入问题并点击 **开始分析** 后才请求服务。

保存只检查格式，不验证连通性或工具调用能力，也不会发起模型请求。分析时会发送问题、源文件名与摘要、工具测量结果和调用轨迹，可能产生费用；不默认发送整份原始采样。

页面设置仅保留在当前服务内存中，多个页面共享。每次保存需重新输入密钥，留空会清除旧值；关闭弹窗清空密钥输入框。可点击 **停用模型** 返回本地规则。重启后需重新填写；若启动时设置了 `SCOPE_BASE_URL`、`SCOPE_MODEL`、`SCOPE_API_KEY`，则重新读取这些环境变量。

模型流程最多六轮请求、十二次工具调用，单次网络请求超时为 45 秒，不自动重试付费请求。具体配置与命令行用法见 [模型说明](docs/USAGE.md#6-配置模型分析)。

## 实时示波怎么用

### 没有设备

进入 **实时示波 → 数据来源：合成演示 → 开始监看**。软件逐帧生成正弦和 PWM，幅度、频率或占空比缓慢变化。点击 **停止监看** 保留最后一帧，点击 **冻结此帧并分析** 将该帧的完整采样交给本地分析。

演示不是仪器数据。刷新间隔与接收帧率不等于 ADC 采样率。

![ScopeAgent 实时演示](docs/live-refined-preview.png)

### 连接真实示波器

当前曲线 / 截图适配器支持匹配的 RIGOL MSO5000 型号：MSO5072、MSO5074、MSO5102、MSO5104、MSO5204、MSO5354。通道按型号基础配置提供，许可升级的额外通道未自动探测。其他设备可尝试读取身份，未适配时不会启用监看。

先准备 Python 3.14+、VISA 后端及硬件依赖：

```powershell
py -3.14 -m venv .venv-hardware
.\.venv-hardware\Scripts\python.exe -m pip install -r requirements-hardware.txt
.\.venv-hardware\Scripts\python.exe ui_server.py
```

1. 将电脑与示波器接入可互通的网络，在示波器面板查当前 IP；USB 使用后端提供的完整 VISA INSTR 地址。
2. 进入 **实时示波 → 实际示波器**，扫描已连接设备；也可填 IP / VISA 地址后点击 **识别这台设备**。
3. 核对厂商、型号和支持状态。选择 **波形曲线** 或 **示波器原屏截图**，再选通道与刷新间隔。
4. 确认允许连接和读取，点击 **开始监看**。曲线每次读取一个模拟通道的 NORMal 采样，最多 10,000 点。
5. 结束时点击 **停止监看**，等会话断开后再修改配置。曲线可冻结分析，截图不提供数值采样或触屏控制。

曲线采集可能改变波形传输设置且不自动恢复。本项目不会发送仪器 RUN/STOP、Autoscale、Reset 或启用输出。“停止监看”结束的是电脑读取，不改变示波器采集状态。

这是周期读取，可能遗漏短暂事件；仪器停止时也可能重复返回同一记录。真实设备、驱动、固件和链路仍需现场验证，不能将演示性能当作实机性能。接线、静态 IP、VISA 与排障详见 [连接指南](docs/USAGE.md#7-可选示波器采集)。

## 命令行分析

使用内置合成记录及配套限值：

```powershell
python scope_agent.py demo/synthetic_waveforms.csv --limits examples/limits.json --metadata examples/metadata.json --output output-demo
```

分析自己的记录：

```powershell
python scope_agent.py your_waveform.csv --question "检查周期与采样限制" --output output-analysis
```

可选参数：`--reference`、`--limits`、`--metadata`；模型模式另加 `--llm`，由 `--base-url`、`--model` 或环境变量提供配置。输出目录必须不存在或为空。更多示例见 [命令行指南](docs/USAGE.md#5-命令行使用方法)。

## 报告与数据保存

完整分析报告包含：

| 文件 | 内容 |
| --- | --- |
| `report.md` | 测量概览、分析说明与补测建议 |
| `analysis.json` | 测量、限值、元数据及源文件哈希 |
| `agent.json` | 分析方式、执行状态和证据引用 |
| `trace.jsonl` | 工具调用参数、结果和状态 |
| `waveform.svg` | 全记录预览，可能与网页缩放窗口不同 |

普通导入的报告不附原始 CSV 或参考 CSV，请自行保管。实时冻结报告另附 `live-frame.csv` 和 `metadata.json`，可以重新导入。

工作台最多暂存最近三份记录，演示也计入；没有历史恢复入口。临时文件位于 `.ui-data`，淘汰或正常停止服务时清理，强制结束可能遗留。报告需要主动导出。

## 验证与已知限制

在项目根目录执行：

```powershell
python -m unittest discover -v
```

前端开发时可使用 Node.js 检查语法（运行工作台不需要 Node.js）：

```powershell
node --check ui/app.js
node --check ui/live.js
```

最近一次完整检查：**72 项，65 项通过，7 项已知缺陷的预期失败**。`OK (expected failures=7)` 不表示全部通过；这些用例保留了错误输入、报告失败、扫描阻塞等问题的复现。具体状态见 [审查记录](docs/REVIEW.md)。

数值、工具循环、本机模拟模型、假设备与 HTTP 流程已测试；浏览器检查覆盖导入、选区、监看、冻结及四档屏宽。未验证真实示波器、Python 3.14 硬件运行环境、外部模型服务和计量精度。

使用时还需注意：

- 周期频率是候选值，FFT 主峰不自动等于基频；非均匀采样会停用周期与 FFT。
- 低占空比 PWM、稀疏脉冲和复杂信号可能无法建立周期，未建立不等于没有信号。
- 本机多页面共享监看与模型配置，快速切换会话仍可能需要刷新恢复；建议单页面使用。
- 无法仅凭波形确定唯一电路根因；未观察到毛刺不能证明不存在。
- 服务仅供当前电脑使用，不应直接作为公网多人服务部署。
